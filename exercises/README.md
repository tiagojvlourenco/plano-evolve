# Animações dos exercícios

Cada ficheiro `.webp` é uma animação de 2 fotogramas (posição inicial e final) do exercício com o mesmo nome em inglês, usada na biblioteca de exercícios da app.

As fotografias vêm do [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), de domínio público (Unlicense). Gerado por `scripts/build-exercise-media.py`.


## Livro do estúdio

As imagens dos exercícios do livro do estúdio (a maioria dos 554 acrescentados) vêm do Excel «Livro de Exercícios» do estúdio, convertidas por `scripts/build-book-media.py` para WebP de, no máximo, 360 px (um exercício com duas imagens dá uma animação de 2 fotogramas). **Atenção:** algumas imagens trazem a marca de água «WorkoutLabs.com»; a autorização para as publicar é do estúdio.
