# Animações dos exercícios

Cada ficheiro `.webp` é uma animação de 2 fotogramas (posição inicial e final) do exercício com o mesmo nome em inglês, usada na biblioteca de exercícios da app.

As fotografias vêm do [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), de domínio público (Unlicense). Gerado por `scripts/build-exercise-media.py`.
